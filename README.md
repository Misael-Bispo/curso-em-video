## Organização

Cada pasta corresponde a uma aula:

| Pasta | Assunto |
|---|---|
| Aula 04 | Primeiros comandos |
| Aula 06 | Tipos primitivos e saída de dados |
| Aula 07 | Operadores aritméticos |
| Aula 08 | Utilizando módulos |
| Aula 09 | Manipulando texto |
| Aula 10 | Condições |
| Aula 11 | Cores no terminal |
| Aula 12 | Condições aninhadas |
| Aula 13 | Estrutura de repetição `for` |
| Aula 14 | Estrutura de repetição `while` |
| Aula 15 | Interrompendo repetições `while` |
| Aula 16 | Tuplas |
| Aula 17 | Listas (partes 1 e 2) |

Dentro das pastas:

- `DesafioNNN-Nome.py` é a minha solução do desafio.
- `DesafioNNNa-...` é a resolução oficial do Guanabara, que refiz acompanhando o vídeo de correção do desafio. Guardo principalmente quando ele usa uma abordagem nova ou resolve de um jeito diferente do meu.
- `DesafioNNNb-...` é mais uma variação do mesmo desafio.
- `testeNN.py` e `ExNNN.py` são exemplos e testes feitos durante as aulas.

O arquivo `Anotações Python.txt` reúne minhas anotações do curso.

## Como rodar

Precisa do [Python 3](https://www.python.org/downloads/) instalado.

```bash
git clone https://github.com/Misael-Bispo/curso-em-video.git
cd curso-em-video
python "Aula 07 - Operadores Aritméticos/Desafio009-Tabuada.py"
```

O Desafio 021 (tocar um MP3) usa a biblioteca `pygame`:

```bash
pip install pygame
```
